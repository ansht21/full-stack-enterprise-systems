This repository contains two complete full-stack projects, each in its own self-contained folder with its own README, setup guide, and source. Together they demonstrate authentication, role-based access control, REST API design, relational data modelling, and modern React frontends — across **two different backend stacks**.

---

## Projects

### 🎓 [Academic Grade Management System](./Academic%20Grade%20Management%20System/)

A role-based **Student Result Management System** that lets a college manage students, faculty, subjects, and marks, then generate and publish semester results with marksheets and rank lists.

| | |
| :--- | :--- |
| **Frontend** | React, Tailwind CSS, React Router, Axios |
| **Backend** | Node.js, Express.js, Sequelize ORM |
| **Database** | MySQL (`schema.sql`, `seed.sql`) |
| **Security** | JWT authentication, bcrypt hashing, role-based access (Admin / Faculty / Student) |
| **Highlights** | Marks entry, one-click result generation, publish/unpublish, automatic grade & SGPA calculation, semester rank list |

→ **[Read the full README](./Academic%20Grade%20Management%20System/README.md)**

---

### 📦 [Warehouse Inventory Management System](./Warehouse%20Inventory%20Management%20System/)

A full-stack warehouse and inventory application managing products, categories, suppliers, purchases, sales, inventory logs, and users, with a metrics dashboard.

| | |
| :--- | :--- |
| **Frontend** | React 18, Vite 5, React Router, Axios, Tailwind CSS |
| **Backend** | Java 21, Spring Boot 3.3.5, Spring Data JPA |
| **Database** | MySQL (production), H2 (tests) — schema auto-managed by Hibernate |
| **Security** | Spring Security + JWT, role-based access |
| **Highlights** | Layered controller/service/repository architecture, auto-generated inventory logs, OpenAPI/Swagger docs, JUnit tests |

→ **[Read the full README](./Warehouse%20Inventory%20Management%20System/README.md)**
